# Background Music Asset

Optional custom audio track:

Place your preferred romantic instrumental audio file at:
`public/audio/bgm.mp3`

Supported formats: MP3, M4A, WAV

Note: If no audio file is provided, the website automatically plays a soothing, procedurally generated romantic piano & ambient strings soundscape using the browser's Web Audio API.
Audio will only start playing after user interaction (such as tapping "OPEN OUR STORY" or the music button).
